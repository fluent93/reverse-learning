# Reverse Learning Framework

**AI output is not the final answer. It is the starting point of learning.**

The Reverse Learning Framework is an academic and practice-oriented framework for generative AI-mediated learning. It explores how learners can transform AI-generated outputs into verified, reconstructed, and explainable understanding.

This repository tracks the development of the Reverse Learning Framework and related outputs, including conceptual papers, checklists, templates, review notes, and future practice tools.

---

## Core Question

The central question of the Reverse Learning Framework is not only:

> Did the learner use AI?

but:

> Can the learner explain, verify, contextualize, and defend the work?

## Seven Stages of Reverse Learning

1. AI-Generated Artifact
2. Learner Skepticism
3. Verification
4. Iterative Prompting
5. Contextual Integration
6. Human Reconstruction
7. Explainable Ownership
