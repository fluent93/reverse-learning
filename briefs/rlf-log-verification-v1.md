## Purpose

AI-generated outputs often appear fluent and authoritative before learners fully understand them. This log helps learners document how they questioned, verified, revised, or removed AI-generated claims or elements — and what they learned through that process.

## Main Verification Log — required fields

| Field | Role |
|-------|------|
| AI-generated claim or element | What the AI presented |
| Why I questioned it | Skepticism rationale (links to Stage 2) |
| Verification method | How the claim was checked |
| Source / evidence used | External or course-grounded evidence |
| Reliability of evidence | Learner's assessment of evidence strength |
| Verification result | Accurate / partially accurate / insufficient / incorrect |
| Decision | Kept / revised / removed / deferred |
| Revision made | What actually changed in the artifact |
| **What I learned** | Learning outcome from verification — **required**; without this, the log is mere fact-checking |

---

## Evidence Quality Guide — required table

| Evidence Type | Stronger Use | Weaker Use |
|---------------|--------------|------------|
| Peer-reviewed source | Used to verify conceptual or empirical claims | Cited without reading or understanding |
| Course material | Used to align with assignment expectations | Used only as decoration |
| Official documentation | Used for technical or policy claims | Used without checking date/version |
| Expert source | Used with context and limitations | Treated as unquestionable authority |
| AI follow-up | Used to generate questions for verification | Treated as verification itself |

**Required sentence (verbatim or equivalent):**

> AI follow-up responses can support verification, but they are not sufficient evidence by themselves.

---

## Weak vs. Strong Verification — required examples

| Weak Verification | Strong Verification |
|-------------------|---------------------|
| "I asked ChatGPT if this was correct." | "I checked the claim against an official source and revised the statement." |
| "The citation looked real." | "I opened the source and confirmed that it supports the claim." |
| "The answer sounded reasonable." | "I compared the answer with course materials and identified one missing condition." |
| "I edited the wording." | "I changed the claim because the evidence only partially supported it." |
